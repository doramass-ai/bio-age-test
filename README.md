# Тест «Биологический возраст»

Веб-квиз: считает биологический возраст по 9 показателям здоровья и показывает разрыв с паспортным возрастом. Портирован из GPT «Healthspan Copilot» (National University of Singapore).

**Прод:** https://bio-age-test-one.vercel.app

---

## Главное, на что обратить внимание

### 1. Возврат в Threads через `?post=`

Кнопка «💬 Вернуться в Threads и поделиться» на экране результата ведёт в **тот пост, из которого человек пришёл**. Для этого при публикации ссылки на квиз добавьте параметр `post` с URL самого поста:

```
https://bio-age-test-one.vercel.app/?post=https://www.threads.com/@wowfit/post/XXXXX
```

- У каждого поста может быть своя ссылка — кнопка вернёт человека именно в него (механика виральности: вернулся → прокомментировал).
- При клике результат человека **автоматически копируется в буфер** («Мой биологический возраст: 33 года (по паспорту 47)… Проверь свой: …») — остаётся вставить его в комментарий. Подсказку об этом человек видит, вернувшись на вкладку теста.
- Если `?post=` не указан или это не threads-ссылка, кнопка ведёт на запасной адрес — константа `LINKS.threadsFallback` в начале `app.js`.
- Вторая кнопка «Узнать больше про WowFit» → `LINKS.wowfit` (сейчас wowfit.ru).

### 2. Копирайт и порядок экранов — это конфиг, не код

Все тексты, подсказки, диапазоны слайдеров и порядок шагов лежат в массиве `STEPS` в `app.js`. Поменять формулировку, эмодзи или переставить вопросы = отредактировать объект, движок трогать не нужно.

### 3. Модель расчёта

- Линейная регрессия, восстановленная из обучающего файла GPT (выборка NHANES/CDC, азиатская когорта, n = 276). Коэффициенты перенесены с полной точностью — расчёт совпадает с оригинальным GPT.
- 9 предикторов: HbA1c, вес, талия, hs-CRP, ЛПВП, систолическое и диастолическое давление, пульс покоя, пол.
- **Паспортный возраст в предсказании не участвует** — он нужен только для разрыва «биология − паспорт» и позиции на шкале.
- Пропущенные ответы («не сдавал / не знаю») заменяются средними обучающей выборки (`MODEL.means`), результат помечается как приблизительный.
- ЛПВП принимается в ммоль/л или мг/дл (в российских бланках — ммоль/л), конвертация ×38,67.

### 4. Честность и ограничения (важно для коммуникаций)

- Это **экспериментальный индекс, а не валидированные «часы старения»** (не PhenoAge/Klemera–Doubal): маленькая выборка, у коэффициентов есть статистические странности (например, вес входит с отрицательным знаком из-за мультиколлинеарности). Разрыв ±10 лет для этой модели — статистически обычное дело.
- Поэтому: категории «моложе/старше» поданы как игровые, оценки отдельных маркеров (✓/!/▲) сделаны по общепринятым медицинским нормам (а не по модели), внизу результата стоит дисклеймер «не заменяет консультацию врача». **Не убирайте дисклеймер и не обещайте медицинскую точность в рекламе.**

### 5. Структура и правки

```
index.html   — каркас страницы
styles.css   — все стили (мобайл-фёрст, максимум 520px)
app.js       — модель (MODEL), ссылки (LINKS), конфиг шагов (STEPS), движок, экран результата
```

Локальный запуск: любой статический сервер, например:

```
python3 -m http.server 8823 -d bio-age-test
```

Деплой (проект `bio-age-test`, команда `wow-fit` на Vercel):

```
cd bio-age-test && vercel deploy --prod
```

### 6. Идеи следующих шагов

- Кастомный домен (например, `bioage.wowfit.ru`) — в настройках проекта Vercel.
- OG-картинка, чтобы ссылка красиво разворачивалась в Threads.
- Сбор контакта перед показом результата (по методологии квиз-воронок).
- Аналитика по шагам (отвалы на каждом экране) перед любыми итерациями копирайта.
